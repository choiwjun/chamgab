## Slide 2. 문제 정의

### 부동산 의사결정, 왜 이렇게 어려울까요?

**시나리오: 강남구에 카페 창업을 고민하는 30대 직장인**

```
1단계: 호갱노노에서 아파트 시세 확인
2단계: 소상공인마당에서 상권 데이터 조회
3단계: 학군온에서 주변 학교 정보 검색
4단계: 부동산플래닛에서 토지 가격 비교
5단계: 네이버 부동산에서 실거래가 재확인
6단계: 엑셀에 수동으로 데이터 정리...
```

**결과: 4~5개 서비스를 번갈아 사용, 데이터 연계 불가, 판단은 여전히 감(感)**

| 기존 서비스 | 제공 정보 | 근본적 한계 |
|-------------|-----------|-------------|
| 호갱노노, 아실 | 아파트 시세 | "왜 이 가격인지" 설명 없음. 상권/학군 무관 |
| 소상공인마당 | 상권 통계 | 성공 확률 예측 없음. 부동산 데이터 단절 |
| 부동산플래닛 | 토지 데이터 | AI 분석 없음. 상업적 활용도 판단 불가 |
| 학군온 | 학교 순위 | 단순 랭킹만. 투자 의사결정 연계 부재 |

> **핵심 문제: 데이터는 넘치지만, "왜?"에 답하는 서비스는 없다**

## Slide 4. 참값만의 3가지 차별화

### ① 설명 가능한 AI (Explainable AI)

> **기존 서비스**: "이 아파트 시세는 8억입니다" (끝)
> **참값**: "이 아파트는 8억이며, 가격의 32%는 역세권 근접성, 24%는 단지 규모, 18%는 학군 프리미엄 때문입니다"

- **SHAP (SHapley Additive exPlanations)** 기반 요인 분석
- 모든 예측에 "왜 이 결과인지" Top 요인을 투명하게 공개
- 아파트: 가격 영향 요인 Top 10 + 기여도(%)
- 상권: 성공/실패 핵심 요인 + SHAP 워터폴 차트

→ **"블랙박스 AI가 아닌, 설명하는 AI"** — 국내 부동산 서비스 중 유일

### ② 크로스 도메인 융합 분석

> **기존**: 아파트는 아파트, 상권은 상권 — 각각 따로
> **참값**: 아파트 + 상권 + 학군 + 토지를 하나의 관점으로 연결

**융합 시나리오:**

| 사용자 상황 | 참값의 크로스 분석 |
|-------------|-------------------|
| "이 아파트 살까?" | AI 적정가 + 주변 학군 품질 + 상권 활성도 종합 |
| "여기서 창업하면?" | 업종별 성공 확률 + 주변 유동인구 + 상권 경쟁도 |
| "이 땅 투자 가치는?" | 토지 시세 + 최적 업종 추천 + 상업적 활용도 점수 |
| "아이 학교 어디?" | 학교별 교육 품질 + 주변 학원가 생태계 + 아파트 시세 |

→ **"4개 서비스를 하나로" — 부동산 의사결정의 원스톱**

### ③ 자동화된 데이터 품질 관리

> **기존**: 수동 업데이트, 데이터 신뢰도 불명
> **참값**: 10종+ 공공 API 자동 수집 + 품질 게이트 자동 검증

- 월별 자동 수집 파이프라인 (국토부, 소상공인진흥공단, 학교알리미 등)
- **품질 게이트**: 수집→검증→배포 자동화 (PASS/FAIL 자동 판정)
- **데이터 출처 투명 표기**: 공식 데이터 vs 추정 데이터 명확 구분
- **신뢰도 점수**: 모든 AI 분석에 0~1 신뢰도 표시

→ **"데이터를 믿을 수 있는 이유를 함께 제공"**

## Slide 5. 핵심 서비스 ① — 아파트 AI 적정가

### "이 아파트의 참값은 얼마일까?"

**AI가 68개 변수를 분석하여 적정가격 산출**

- 전국 **33,600+** 아파트 단지 커버
- 실거래가 **1,059,905건** 기반 학습
- XGBoost 모델 정확도: **MAPE 12.88%** (A등급), R² 0.93
- SHAP 기반 가격 요인 투명 공개

**68개 변수가 만드는 정밀 분석:**

| 카테고리 | 포함 변수 | 기존 서비스 대비 |
|----------|-----------|-----------------|
| 기본 정보 | 면적, 층수, 연식, 세대수 | 동일 |
| 교통 접근성 | 지하철역 거리, 버스정류장 밀도 | 일부만 반영 |
| 생활 인프라 | 편의점, 대형마트, 병원, 공원 (POI) | **참값만 반영** |
| 교육 환경 | 초·중·고 거리, 학원 밀도 | **참값만 반영** |
| 건물 품질 | 주차대수, 난방방식, 엘리베이터 | **참값만 반영** |
| 지역 시세 | 시군구 평균가, 거래 활성도 | 일부만 반영 |

**차별화 기능:**
- AI 적정가 vs 실거래가 **갭 분석** → "이 매물은 시세 대비 저평가/고평가"
- 가격 영향 요인 Top 10 — SHAP 차트로 시각화
- **신뢰도 점수 (0.71~0.91)** — 분석 결과를 얼마나 믿을 수 있는지 함께 제공
- AI 분석 리포트: **162,957건** 생성 완료

## Slide 6. 핵심 서비스 ② — AI 상권분석

### "이 위치에서 창업하면 성공할까?"

**ML 모델이 예측하는 업종별 성공 확률**

- 전국 **130개** 시군구, **46개** 업종 분석
- XGBoost 분류 모델 정확도: **86.3%** (A등급)
- F1 Score: **88.25%**, AUC: **94.91%**

**기존 서비스와의 근본적 차이:**

| 구분 | 소상공인마당 | 참값 |
|------|-------------|------|
| 제공 정보 | 점포 수, 매출 통계 (과거 데이터) | **성공 확률 예측** (미래 예측) |
| 분석 방식 | 통계 요약 | **ML 모델 + SHAP 요인 분석** |
| 업종 추천 | 없음 | **지역 맞춤 최적 업종 추천** |
| 비교 기능 | 없음 | **지역간 상권 비교 분석** |
| 인사이트 | 숫자 나열 | **"왜 성공/실패하는지" 이유 제시** |

**핵심 기능:**
- 업종별 성공 확률: **Strong / Promising / Neutral / High Risk** 4단계
- SHAP 기반 성공/실패 요인 — "이 지역에서 카페가 잘 되는 이유"
- 유동인구 + 매출 + 경쟁현황 종합 분석
- 데이터: 점포 143,520건 + 매출 143,520건 + 유동인구 1,170건

## Slide 7. 핵심 서비스 ③ — 학군 분석

### "우리 아이 학교, 어디가 좋을까?"

**공식 교육 데이터 기반 학군 품질 분석**

- 전국 **12,615개** 학교 (초·중·고 전수)
- **107,817개** 학원 정보
- **228개** 시군구 전국 커버리지
- **3개 공식 API** 연동: 학교알리미 + NEIS + 한국교육개발원

**기존 서비스와의 차이:**

| 구분 | 학군온 | 참값 |
|------|--------|------|
| 데이터 범위 | 고등학교 위주 | 초·중·고 **전체** |
| 분석 깊이 | 단순 순위 | **종합 점수 + 세부 지표** |
| 학원 정보 | 없음 | **학원가 생태계 분석** (밀도, 과목, 수강료) |
| 데이터 출처 | 불명 | **공식/추정 데이터 투명 구분** |
| 부동산 연계 | 없음 | **주변 아파트 시세 연동** |

**핵심 기능:**
- 시군구별 종합 교육 품질 점수 (5개 축: 진학률, 교육환경, 학원 밀도, 접근성, 수강료)
- 학교별 상세: 진학률, 학급당 학생수, 교육환경 지표
- 학원가 생태계 분석: 밀도, 과목 다양성, 접근성, 평균 수강료
- **데이터 신뢰도 100%**: 전국 12,615교 전수 공식 데이터 확보

## Slide 8. 핵심 서비스 ④ — 토지 투자 분석

### "이 땅의 가치를 참값이 알려드립니다"

**전국 토지 실거래 데이터 통합 + 상권 융합 분석**

- 토지 실거래: **1,003,369건** 수집 완료
- 서울 22/25구, 경기 35/42 시군구 커버
- 2021~2026년 **5년치** 거래 데이터

**3단계 로드맵 — 참값만의 토지×상권 융합:**

| Stage | 내용 | 차별화 |
|-------|------|--------|
| **Stage 1** (현재) | 토지 정보 통합 — 지역별 시세, 지목별 검색, 실거래 이력 | 100만건+ 실거래 기반 |
| **Stage 2** (예정) | **토지 × 상권 융합** — 토지 위치 기반 최적 업종 추천, 상업적 활용도 점수 | **국내 유일**: 토지+상권 AI 연계 |
| **Stage 3** (장기) | **토지 AI 적정가** — XGBoost 토지 전용 모델 | 아파트 모델 기술 재활용 |

> **Stage 2가 핵심**: "이 대지에서 어떤 업종이 가장 성공할까?"
> → 기존 상권분석 AI 모델을 토지 분석에 그대로 적용
> → 부동산 중개업소, 개발사에게 즉시 가치를 제공하는 B2B 모델

## Slide 11. 사용자 시나리오 & 확장성

### 참값이 만드는 의사결정 경험

**시나리오 A: 아파트 구매자**
```
강남구 래미안에 관심 → 참값 검색
→ AI 적정가: 12.3억 (현재 호가 대비 5% 저평가)
→ 가격 요인: "역세권 +2.1억, 대단지 +1.5억, 학군 +0.9억"
→ 주변 학군 분석: "서울고 진학률 상위 15%, 학원 밀도 A등급"
→ 의사결정: 데이터 기반으로 매수 결정
```

**시나리오 B: 예비 창업자**
```
서초구에서 카페 창업 고려 → 참값 상권분석
→ 성공 확률: 72% (Promising)
→ 핵심 요인: "유동인구 상위 20%, 경쟁 밀도 중간, 매출 성장세"
→ 주변 토지 분석: "임대료 대비 매출 효율 상위 지역"
→ 의사결정: 데이터 기반으로 업종/입지 확정
```

**시나리오 C: 학부모**
```
자녀 진학 위해 이사 검토 → 참값 학군분석
→ 강남구 종합 교육 품질 89점 (전국 상위 3%)
→ 진학률 + 학원가 생태계 + 학급당 학생수 종합 비교
→ 추천 아파트: "학군 프리미엄 반영 AI 적정가 제공"
→ 의사결정: 학군 + 시세를 동시에 고려한 이사 결정
```

**확장 가능성:**
- 토지 × 상권 융합 → **창업 부지 추천** (B2B)
- 아파트 × 학군 융합 → **학부모 맞춤 추천** (B2C)
- B2B API → 부동산 중개업소, 금융기관, 건설사에 데이터 API 제공
